# Developer Lab

A hands-on collection of multi-language projects created to explore software engineering, backend development, algorithms, testing, and architecture.

## Purpose

This repository documents my progress as a developer through practical projects written in different programming languages.

Each project focuses on specific concepts, challenges, and professional practices. The goal is not only to make things work, but also to understand, test, improve, and explain them.

## What I will explore

- C#, Java, Python, TypeScript, and SQL
- Object-oriented programming and design
- APIs and backend development
- Algorithms and data structures
- Automated testing
- Databases
- Docker and CI/CD
- Security and application architecture
