# Developer Lab

A hands-on, multi-language portfolio focused on one simple goal: **show what I can understand, implement and explain myself as a developer**.

This repository complements my training repository, [`Learning`](https://github.com/mjodheim/Learning), with smaller and more deliberate projects built around debugging, algorithms, testing, architecture, backend development and production practices.

## Authorship & AI assistance

The implementation work in this repository is done manually by me as part of my learning process.

AI may be used as a **tutor**, for example to:

- explain a concept;
- ask guiding questions;
- provide hints when I am stuck;
- review code I have written;
- challenge design choices;
- suggest additional test cases or edge cases.

AI is **not intended to provide the completed implementation** for these exercises.

When a project starts from supplied starter code, an exercise template or any substantial external contribution, that origin should be documented in the project itself.

The objective is not to claim that I work without modern tools. It is to make the distinction clear between **code I can write and defend myself** and larger projects where AI is deliberately part of the engineering workflow.

## Project standard

As the repository matures, completed projects should aim to include:

```text
project/
├── README.md        # what the project does and how to run it
├── EXERCISE.md      # original challenge when applicable
├── src/             # implementation
├── tests/           # automated tests when relevant
└── DECISIONS.md     # important design choices for larger projects
```

Not every small exercise needs every file. The important part is that I can explain **what I built, why I built it that way, what failed, and what I learned**.
